# Match Fix Promotional Video Bootstrap

## Project role

Create a standalone promotional video for **Match Fix** centered on visual reasoning, exact-move constraints, and the satisfying physical transformation of a wrong equation into a correct one.

Source project: `fiverocks-dev/match-fix`

## Evidence-grounded game definition

Match Fix is a browser-first matchstick equation puzzle.

Current development direction and implemented domain behavior include:

- The player begins from an incorrect equation built from matchstick-style symbols.
- A puzzle requires moving the configured exact number of matchsticks.
- The final equation must be mathematically valid.
- A solution that reaches a valid equation with the wrong move count is not equivalent to satisfying the puzzle constraint.
- Content is organized into five difficulty packs with a larger puzzle set.
- Earlier packs focus on exact-one-move puzzles; higher difficulty introduces exact-two-move puzzles.
- Division is present in higher-difficulty content.
- Current metagame work includes hints, mastery records, Daily Spin, sharing, and Infinite Mode.
- Infinite Mode is designed around a timed continuous-solving loop with time added on success.

Formal production/publication status must be re-checked before final advertising language.

## Core promotional hook

**Move one thing. Change the whole equation.**

Alternative Korean framing:

**성냥 하나를 옮기면, 식 전체가 달라진다.**

The strongest visual chain is:

`inspect wrong equation -> discover the move -> drag matchstick -> equation changes -> success`

## Audience experience to communicate

The viewer should understand that:

1. the puzzle is solved by physically transforming the equation,
2. the move count is part of the challenge,
3. arithmetic and spatial reasoning happen together,
4. the payoff is visible in a single compact before/after transformation.

## Hero footage

Priority capture moments:

1. A visually simple incorrect equation readable in under one second.
2. A deliberate pause while the player studies it.
3. One matchstick being selected and dragged.
4. The destination position clearly visible before placement.
5. Matchstick drop producing a valid equation and success feedback.
6. A second, more surprising puzzle showing a different operator transformation.
7. Optional exact-two-move puzzle for escalation.
8. Optional Infinite Mode countdown/rapid solving only if current playable status is verified and the standalone concept needs a speed-oriented ending.

## Creative rhythm

Recommended standalone video rhythm:

`LOOK -> QUESTION -> NOTICE -> MOVE -> CLICK -> SOLVED`

Unlike Math Fighter or Math Rain, this video should embrace silence and anticipation. The physical click/drop should be the sensory payoff.

## Visual identity hypothesis

- Minimal, deliberate camera/edit movement.
- Keep the equation large and readable.
- Emphasize hand/cursor motion and exact placement.
- Use subtle tension sound before the move, then a crisp placement/success sound.
- Favor clever transformations over rapid montage for the opening hook.

## Claims to avoid without re-verification

Do not claim without current verification:

- formal public release/production status,
- exact total puzzle count if the production branch/content inventory changes,
- all metagame systems as generally available if still prerelease,
- educational efficacy or quantified reasoning improvement,
- that every puzzle has a unique solution unless current generator/content validation explicitly guarantees it.
