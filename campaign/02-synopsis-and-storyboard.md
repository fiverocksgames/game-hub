# Game Hub Google Ads Brand Video

## Working concept

**THINK. CHOOSE. ACT.**

The video presents FiveRocks games through a repeated pattern: the player understands a situation, makes a decision, and turns that decision into a visible game action.

## Synopsis

A problem appears. The answer alone is not the end of play. Across different FiveRocks games, thinking becomes a concrete action: selecting the right target, choosing an answer under time pressure, remembering a card position, turning earned resources into a tactical setup, or moving a matchstick to repair an equation.

The games are different in genre, but the player is always asked to turn judgment into action. The film ends by gathering the games into Game Hub and closing with the FiveRocks Games brand.

## 30-second storyboard

### 0:00-0:02 — Hook
A simple problem appears, followed by the line: **Knowing the answer is only the beginning.**

### 0:02-0:06 — Math Fighter
Show the arithmetic prompt, multiple answer-bearing enemies, target selection, and the correct target being cleared. On-screen words: **THINK. TARGET. ACT.**

### 0:06-0:10 — Math Rain
Show falling problems and answer cards. A correct choice clears a problem; a wrong choice may be used briefly to show the remaining problems move closer to danger. On-screen words: **CALCULATE. REACT.**

### 0:10-0:14 — Memory Game
Briefly reveal several cards, hide them, then show the player selecting a remembered pair. On-screen words: **LOOK. REMEMBER. CHOOSE.**

### 0:14-0:20 — Math Defender
Show a correct math answer awarding preparation currency, Scout information, hero selection/deployment, then the resulting battle. On-screen words: **EARN. ANALYZE. PLAN.**

### 0:20-0:24 — Match Fix
Slow the pace. Show an incorrect matchstick equation, move the required matchstick, and reveal the corrected equation. On-screen words: **SEE. MOVE. SOLVE.**

### 0:24-0:27 — Montage
Rapid cuts across the five games. Build the phrase: **THINK. CHOOSE. ACT.**

### 0:27-0:30 — Game Hub / End card
Show the Game Hub collection view, then FiveRocks Games branding and **Play. Think. Grow.** with a Game Hub CTA.

## Production rule

Each game should be represented by an actual implemented gameplay interaction. Avoid depicting planned or unverified features as if they are already playable.
